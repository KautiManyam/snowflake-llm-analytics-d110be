# Snowflake | Enterprise LLM Agent for Data Analytics

An intermediate capstone — design a FastAPI contract, run governed SQL on Snowflake via Snowpark, persist users/datasets/query-logs in Postgres, gate access with API keys, ground an LLM in schema+docs with lightweight RAG, generate SQL with OpenAI structured outputs, orchestrate retrieval→generate→validate→execute→summarize as a LangGraph state machine, cache with Redis, add structured observability, emit chart specs, and harden every failure mode.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- Python
- FastAPI
- Snowpark
- OpenAI
- LangGraph
- Postgres
- Redis
